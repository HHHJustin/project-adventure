# 專案冒險（原型）

把專案進度畫成一個橫向關卡的小遊戲。每個階段是一個房間，房間裡放著這一關要交的文件、待辦、要打交道的人，以及過關的門。

線上試玩：https://hhhjustin.github.io/project-adventure/

> 這是概念原型。頁面上的專案、人物、任務全部是虛構的示範資料。

## 怎麼玩

用滑鼠點畫面上的東西，角色會走過去，下方顯示內容。

| 畫面上的東西 | 代表 |
| --- | --- |
| 階段立牌 | 這一關的總覽；名稱、日期、過關條件點一下可以修改 |
| 台座上的文件 | 這一關要交的文件。綠勾＝已確認、橘點＝進行中、灰色＝還缺 |
| 白板 | 任務板。做完的事打勾；還沒完成可以「記進度」或「改期」 |
| 警告牌 | 事件簿。記下發生了什麼事、哪一天、對後面的影響 |
| 人物 | 這一關要打交道的對象。看手錶＝有事在他手上、冒汗＝有逾期 |
| 玻璃門 | 過關目標，條件都完成才算過關 |

## 出牌、預測、對答案

結果不確定、要等別人的事，可以「出牌」：

1. 選一個做法（寄信給期限、打電話、約會議、往上報……）。
2. 寫下你猜會怎樣、幾成把握、哪一天對答案。
3. 到了那天回來「對答案」：猜中、中一半或沒中，並寫一句學到什麼。

右邊的「打法統計」會告訴你哪種做法最常成功，「戰績」會告訴你說的把握準不準。

## 資料

- 預設是內建的示範資料，所有操作只存在你自己的瀏覽器。
- 也可以用 Chrome 連結本機的資料夾讀寫自己的專案檔；資料只在本機，不會上傳到任何地方。
- 這個 repository 不含任何真實專案資料。

## 做法

單一個 `index.html`，沒有框架、不需要安裝。用 Chrome 直接開啟，或放在任何靜態網頁空間即可。網址加上 `?selftest` 會用示範資料跑一次自我檢查。
